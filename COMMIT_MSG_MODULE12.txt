Module 12: Cross-Platform Mobile Application (Flutter)

Add apps/mobile, a Flutter app (Clean Architecture, feature-first,
Riverpod, GoRouter, Dio, Hive + sqflite) joining apps/web and
apps/desktop as a third first-class client of apps/api.

Features:
- Auth: full Module 1 integration (email/Google/GitHub, MFA, refresh
  rotation, session management, biometrics/PIN device lock, secure
  token storage)
- Dashboard: workspace stats, pinned projects, latest findings,
  recent activity, quick actions
- Offline-first Projects/Targets/Findings via a shared SyncEngine/
  outbox pattern (optimistic local writes, sync-on-reconnect through
  a per-entity SyncPushHandler)
- Reports: view/AI-draft-generate/export/download/share
- AI Security Copilot (Module 11 integration): streaming chat over a
  hand-rolled SSE client, Markdown/syntax-highlighted code/Mermaid
  rendering, voice push-to-talk, Master Orchestrator run tracking,
  Knowledge Base search
- Voice: on-device STT/TTS wired into the AI chat composer
- Notifications, Evidence Capture (camera/gallery/file/video/mic/QR,
  on-device SHA-256 hashing, offline upload queue), File Manager,
  Global Search (online + offline FTS5 fallback)
- Settings (incl. Module 11 Privacy Mode), Workspace, Analytics
  (fl_chart)
- Security hardening: encrypted local storage, certificate pinning,
  jailbreak/root detection, clipboard auto-clear, session timeout,
  remote logout
- CI/CD: .github/workflows/mobile-ci.yml (analyze/test/Android
  APK+AAB/iOS no-codesign build) + Fastlane lanes for both platforms

Architecture:
- Deliberately avoids Freezed/riverpod_generator/json_serializable
  codegen in favor of Dart 3 native sealed-class state unions, since
  the authoring sandbox had no reachable Flutter/Dart toolchain at
  all (storage.googleapis.com, where the Flutter engine/Dart SDK are
  hosted, is blocked by the network allowlist). Every file was
  hand-authored and manually cross-referenced against real
  packages/shared contracts instead of compiler-verified. Full
  account in docs/adr/0012-mobile-application.md.
- Manual review caught and fixed three self-authored bugs: a
  malformed color hex literal, a ProviderContainer
  double-construction bug in main.dart's bootstrap, and a
  data-mapping typo in the Analytics bar chart.

Known limitations (see docs/releases/module-12-release-notes.md):
- android/ and ios/ contain only hand-authored AndroidManifest.xml/
  Info.plist partials; the Gradle/Xcode native scaffold must be
  generated on a real machine via
  `flutter create --platforms=android,ios .` before this module
  builds at all.
- flutter analyze / flutter test / flutter build have not been run
  against this source (no Flutter SDK reachable in this sandbox).
- iOS IPA generation requires macOS + Xcode, independent of sandbox.
- Several features have disclosed partial scope (finding comments/
  attachments timeline, Recon/Scanner job dashboards, native
  DOCX/PDF in-app preview, AI chat branching/bookmarks screen,
  document-scanner edge detection, in-app language switcher,
  screenshot-protection runtime toggle, cursor-based pagination,
  background workmanager sync task).
- Integration/golden/offline/sync/performance test suites (5 of 7
  spec testing categories) not written this pass.
