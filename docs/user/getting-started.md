# Getting Started

Secora scans your website for security problems, explains what it found, and shows how to fix it. This guide takes you from sign-up to your first scan.

> **Only scan what you own or are allowed to test.** See the [Acceptable Use Policy](/legal/acceptable-use).

## 1. Create an account

Open [secora.group](https://secora.group), choose **Get started free** (or sign in with Google or GitHub), and accept the Terms, Acceptable Use Policy and Privacy Policy. If you used email and password, confirm your address with the link we send.

## 2. Create a project

A **workspace** is created for you automatically. Inside it, go to **Projects → New project** and give it a name. A project groups the work for one website, client or program.

## 3. Add your first target

A **target** is the asset you want to test: a domain, URL or IP address.

1. Open your project and choose **Add target**.
2. Enter the value (for example `example.com`).
3. Say how you are allowed to test it: you own it, you have written permission, or it is in a bug bounty scope. Confirm the checkbox.
4. Set the scope status to **In scope**.

Scans stay blocked until the target has a valid authorization. Private, internal and some government addresses cannot be scanned from the hosted service.
